# Detona Ralph Web

Bem-vindo ao [**Detona Ralph Web**](https://douglas-oc.github.io/jogo-detona-ralph/)! Este repositório contém um jogo interativo baseado no famoso personagem "Detona Ralph". O objetivo é testar sua agilidade e precisão ao clicar no Ralph enquanto ele se move pelos quadrados da tela.

## 🚀 Tecnologias Utilizadas

O jogo foi desenvolvido utilizando as seguintes tecnologias:

- **HTML5 e CSS3**: Estrutura e estilo do jogo.
- **JavaScript**: Lógica de programação e interatividade.
- **Sprites e imagens customizadas**: Criação da estética visual baseada no universo de Detona Ralph.

## 🎮 Como Jogar

1. Ralph aparecerá aleatoriamente em diferentes quadrados da tela.
2. **Clique no quadrado correto** para marcar pontos.
3. Se clicar em um quadrado errado, você **perde uma vida**.
4. Você começa com **3 vidas**. Caso elas acabem, o jogo termina.
5. O objetivo é **acumular a maior pontuação possível** antes de perder todas as vidas!

## 🏆 Funcionalidades

- **Sistema de Pontuação**: Acompanhe seu progresso e tente bater seu recorde.
- **Sistema de Vidas**: Comece com 3 vidas e tente sobreviver o máximo possível.
- **Interface Interativa**: Gráficos simples e dinâmicos para uma jogabilidade envolvente.
- **Jogabilidade Responsiva**: O jogo funciona em diferentes dispositivos e tamanhos de tela.

## 🔧 Como Executar o Projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/jogo-detona-ralph.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd jogo-detona-ralph
   ```
3. Abra o arquivo `index.html` no navegador.
4. Divirta-se jogando!
